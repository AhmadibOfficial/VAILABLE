# VAILABLE — Instructions for AI coding tools

These instructions are not an operating-system security boundary. A Git worktree and .gitignore do **not** prevent the AI from reading other files.

- Work only on the scoped task with synthetic fixtures inside an audited restricted container/VM that mounts only approved project files.
- Never read, list, index, paste, transmit or modify credentials, .env files, client documents, personal data, host keys, production logs, external repositories or proprietary algorithms.
- Minimize prompt context to task acceptance criteria, targeted code sections and needed security guidance. Sanitize errors before sharing.
- Treat generated changes as untrusted. Do not install unreviewed dependencies, execute arbitrary downloaded scripts, disable tests, modify automation policy or alter CI.
- No production keys, cloud deployment roles or merge permissions. Never change main, merge PRs, deploy or purchase services.
- Keep unfinished capabilities labelled Coming Soon. Run tests and document verified limitations.
- No claim of zero-data-retention or no-model-training without a verified provider agreement.

Refer to engineering/AUTONOMY_POLICY.md and docs/security/AI_ASSISTED_DEV.md.
